AI AGENT 产品COURSE CATALOG / 05

AI AGENT PRODUCT · WEEKEND PROGRAM

Ai agent 产品就业系统课

以求职为目标，从 Agent 产品通识出发，先补齐大模型从数据、训练、对齐到评测的底层能力，再带学员完成 Agent 设计，并拆解大厂真实 AI 业务项目。五周完成可用于投递和面试的 Agent 产品作品集。

每周六、周日上课上午 10:00–12:30下午 14:00–17:00周中：产品交流会 · 周刊领读 · 作业点评5 周 · 10 天 · 20 个半天

WEEK 01 · 产品通识

Agent 产品通识

01WEEKS

先建立 AI 行业与 Agent 产品的全局认知，听懂行业语言，用熟上手工具。

周六DAY 01
上午

AI 产品岗位地图与职业规划

开营；行业标准、岗位职责、能力模型与课程安排。

下午

AI 行业专业名词解析

模型基础：大模型、Token、上下文窗口、幻觉；模型训练：预训练、SFT、RLHF、LoRA；应用技术：RAG、Agent、Workflow、MCP、Function Calling；评测：评测集、Badcase、Benchmark。结合真实产品场景讲解。

作业

整理 AI 名词卡片，拆解 3 份目标岗位 JD 中的专业术语。

周日DAY 02
上午

AI 效率工具与协作软件

ChatGPT、Claude、豆包、Kimi；飞书文档与多维表格；Cherry Studio；Prompt 基础写法与图片/视频/音频生成工具。

下午

Agent 搭建与开发工具入门

Dify、Coze；Cursor、Claude Code / Codex 安装与配置；GitHub 基础操作，完成第一个能跑起来的小工具。

作业

完成软件环境配置，提交工具使用笔记与一个 Dify/Coze 小应用。

本周产出AI 名词卡片 · 岗位术语拆解 · 工具使用笔记 · 第一个 Dify/Coze 小应用
周中任务每项约 3 小时
周二产品交流会学员分享产品体验与项目进展，互相提问、找问题。
周三周刊领读领读 AI 周刊中的专业文章，梳理行业动态与方法论。
周五作业点评点评名词卡片、岗位术语拆解与第一个小应用。

WEEK 02 · 模型底层

AI 训练全链路与模型能力

02WEEKS

参考 AI 训练师的工作链路：需求 → 数据 → 训练 → 评测 → 上线 → 反馈，理解模型能力从哪里来、如何被评估与改进。

周六DAY 03
上午

训练链路与数据准备

业务目标与能力边界；数据采集、清洗、标注、去重，数据集构建与标注规则文档。

下午

预训练、SFT 与 LoRA 微调实操

Instruction-Response 样本、CoT 分步推理样本；LoRA 训练带练。

作业

标注规范 V1、SFT 样本集与 LoRA 训练实操记录。

周日DAY 04
上午

对齐训练与偏好数据

Reward 模型、RLHF / RLAIF / DPO；成对比较答案与安全判断。

下午

模型评测、上线验收与数据回流

能力、场景、安全评测与 Benchmark 构建；A/B Test、回归测试、上线 Gate 与红线测试；Badcase 回流。

作业

偏好数据样例、一份小型评测集与评测报告 V1。

本周产出标注规范 · SFT / 偏好样本 · LoRA 实操记录 · 评测报告
周中任务每项约 3 小时
周二产品交流会学员分享产品体验与项目进展，互相提问、找问题。
周三周刊领读领读 AI 周刊中的专业文章，梳理行业动态与方法论。
周五作业点评点评数据规范、训练样本与评测报告。
